  How to read it. Tables identical at the same q: the two scales
  turn q into the same quantisation tables; a size or PSNR
  difference then comes from how the tables are applied, which
  the file does not show. Tables different: the scales do not
  correspond, and 'nv q for fv size' is the pair to compare at.
  The search runs from two starting intervals; if both land on
  the same q, that q is a property of the scales, not of the
  search. PSNR: every file decoded by the same decoder (nvJPEG
  CUDA) so it compares the encoders; a watermark rectangle, if
  found, is left out on both sides.
